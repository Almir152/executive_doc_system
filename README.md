# Единая система управления исполнительной документацией

Автономное локальное настольное приложение (GUI) для автоматизации учета, валидации и формирования комплектов исполнительной документации (АОСР, АООК, исполнительные схемы, сертификаты) на строительных объектах.

Разработано строго в соответствии с ТЗ. Поддерживает работу на **Windows 10/11** и **Linux** (Arch, Ubuntu, Debian).

---

## 🚀 Основные возможности

* **Единое ядро и ORM (SQLAlchemy + SQLite):** Полная привязка всех документов, схем и сертификатов к единому объекту — «Проект».
* **Дедупликация файлов (SHA-256):** Автоматический расчет хэша загружаемых PDF-файлов. Файлы хранятся в архиве в единственном экземпляре и связываются с актами через отношение `Many-to-Many`.
* **Валидация бизнес-логики:** Встроенный контроль хронологии и дат актов освидетельствования (АОСР -> АООК).
* **Безопасный AI Connector:** Изолированный модуль ИИ-анализа без прямого доступа к файловой системе или базе данных.
* **Генерация PDF по ГОСТ/A4:** Автоматическая верстка и экспорт реестров документации с полной поддержкой кириллицы (ReportLab).
* **Графический интерфейс (PyQt6):** Удобный двухпанельный интерфейс с навигацией, таблицами и диалогами управления.

---

### 🪟 Инструкция для Windows (10 / 11)

#### Шаг 1. Подготовка системы (Python)
1. Убедитесь, что на ПК установлен **Python 3.10** или более новая версия.
   * Скачать Python для Windows: [python.org/downloads](https://www.python.org/downloads/)
   * ⚠️ **ОБЯЗАТЕЛЬНО:** При установке поставьте галочку **"Add python.exe to PATH"** на самом первом экране инсталлятора!

#### Шаг 2. Скачивание исходного кода
Выберите один из двух способов:
* **Способ А (ZIP-архив без использования Git):**
  1. Перейдите на страницу репозитория: `https://github.com/Almir152/executive_doc_system`.
  2. Нажмите зеленую кнопку **`<Code>`** -> **`Download ZIP`**.
  3. Распакуйте скачанный архив в любую папку (например, `C:\executive_doc_system`).
* **Способ Б (Через Git):**
  Откройте **Командную строку (`cmd`)** или **PowerShell** и выполните:
  ```cmd
  git clone https://github.com/Almir152/executive_doc_system.git
  cd executive_doc_system
  ```

#### Шаг 3. Настройка виртуального окружения и запуск
Откройте **Командную строку (`cmd`)** или **PowerShell** в папке с проектом:

```cmd
:: 1. Создаем изолированное виртуальное окружение
python -m venv venv

:: 2. Активируем виртуальное окружение
venv\Scripts\activate

:: 3. Обновляем менеджер пакетов pip и устанавливаем зависимости
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install pytest-qt pyinstaller

:: 4. Запускаем приложение
python main.py
```

## 📖 Руководство пользователя (Как пользоваться приложением)

После запуска `python main.py` откроется главное окно программы с боковой панелью навигации слева и рабочей областью справа.

### 1. Управление проектами
* **Просмотр списка проектов:** Нажмите на пункт **«Проекты»** в левом меню. В таблице отобразятся все существующие строительные объекты, их направления и адреса.
* **Создание нового объекта:** Нажмите кнопку **`+ Создать проект`** над таблицей.
  1. Введите наименование проекта (например, *«Строительство лабораторного корпуса МФТИ»*).
  2. Выберите направление работ из списка (*Общестроительные работы*, *Внутренние инженерные сети* или *Наружные инженерные сети*).
  3. Проект сохранится в локальную базу данных и сразу появится в списке.

### 2. Работа с документами и единым архивом файлов
* **Привязка документов (АОСР / АООК):** Все акты привязываются к выбранному проекту.
* **Загрузка схем и сертификатов:** При добавлении PDF-файлов система автоматически вычисляет их **SHA-256 хэш**.
* **Автоматическая дедупликация:** Если один и тот же сертификат или типовая схема прикрепляется к нескольким актам, система сохранит ровно одну физическую копию файла в `storage/internal_archive/`, исключая дублирование на диске.

### 3. Проверка связей и дат с помощью ИИ (AI Connector)
1. Перейдите в раздел **«ИИ-Агент»** в левом меню или нажмите кнопку **«Запустить ИИ-проверку связей»** внизу окна.
2. ИИ в безопасном режиме проанализирует корректность цепочки документов (проверит, что даты АООК не опережают связанные АОСР).
3. В текстовом поле ниже появится результат анализа и рекомендации ИИ. Модуль работает изоляционно и не может изменить данные без вашего подтверждения.

### 4. Экспорт комплекта и генерация PDF-реестра
* При выгрузке проекта система автоматически создаёт папку в `storage/packages/`.
* Формируется итоговый **Реестр исполнительной документации** формата A4 на русском языке (кириллица полностью поддерживается).

## 📦 Сборка автономного исполняемого файла (.exe / binary)

Чтобы запустить приложение на ПК без необходимости ставить Python:

* **На Windows (PowerShell / CMD):**
  ```cmd
  pyinstaller --noconfirm --onedir --windowed --name "ExecutiveDocSystem" main.py
  ```
  *Готовый запускной файл `ExecutiveDocSystem.exe` появится в папке `dist\ExecutiveDocSystem\`.*

* **На Linux (Терминал):**
  ```bash
  pyinstaller --noconfirm --onedir --windowed --name "ExecutiveDocSystem" main.py
  ```
  *Исполняемый файл появится в папке `dist/ExecutiveDocSystem/ExecutiveDocSystem`.*
